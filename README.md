# otel-native-mycli

『OTel Native な自作 CLI ツールを作ろう』のサンプルリポジトリです。

OpenTelemetry を最初から組み込んだ（OTel Native）CLI ツール`mycli`を、Hello World を題材にゼロから作っていく実践コードを収録しています。Go・kong・OpenTelemetry SDK・Jaeger を使用します。

## 書籍の誤植などの報告について

書籍の誤植などの報告については Issue にてお願いします。
このリポジトリは自動生成しています。
そのため Pull Request による修正はせず、適宜修正版を force push でリリースさせていただきます。
